# AI-Assisted Marketing Landing Page — Bitrix24 Concept

A responsive marketing landing page concept inspired by Bitrix24, featuring an interactive quiz, personalized recommendations, and a demo lead capture form.

This project was created for portfolio and educational purposes. It is an independent concept and is **not an official Bitrix24 website or affiliated project**.

## Overview

The goal of this project was to create a modern marketing landing page that demonstrates responsive frontend development and the practical use of AI-assisted coding tools.

The page combines a promotional layout, interface mockups, interactive elements, and a lead generation flow to simulate a real-world marketing website.

AI tools were used to assist with planning and development. The generated code and interface behavior were reviewed and refined as part of the development process.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Interactive multi-step quiz
- Personalized recommendations based on user answers
- Demo lead capture form with client-side interaction
- Dashboard-style UI mockup
- Mobile navigation
- Responsive cards and content sections
- Semantic HTML structure
- CSS-based styling and interface elements

## Tech Stack

- **HTML5** — semantic page structure
- **CSS3** — responsive layouts, styling, and interface components
- **Vanilla JavaScript** — quiz logic, recommendation flow, and form interactions
- **Google Fonts** — Manrope typography
- **AI-assisted development** — AI-supported planning, code generation, debugging, and refinement

No frameworks, build tools, or package dependencies are required.

## Getting Started

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/PurpleeHead/bitrix24-ai-landing.git
   ```

2. Open the project folder:

   ```bash
   cd bitrix24-ai-landing
   ```

3. Open `index.html` in your browser.

For a more convenient development workflow, open the folder in VS Code and use the Live Server extension.

No build process or dependency installation is needed.

## Testing Checklist

The following scenarios can be used to verify the main interactions:

- [ ] Check the layout at different viewport widths.
- [ ] Test the mobile navigation.
- [ ] Complete the quiz and verify that the recommendation changes according to the first answer.
- [ ] Try to proceed without selecting an answer.
- [ ] Complete the final quiz step and request a recommendation.
- [ ] Fill out and submit the demo lead form.
- [ ] Check the layout at mobile widths of 375–430 px.
- [ ] Verify that the interface remains usable when the Google Fonts connection is unavailable.

## AI-Assisted Workflow

AI tools supported the development process, including planning the page structure, generating implementation ideas, and assisting with code refinement.

The project also demonstrates the importance of reviewing AI-generated code rather than relying on generated output without verification.

The development workflow included:

- Using prompts to define the page structure and expected behavior
- Reviewing and refining generated HTML, CSS, and JavaScript
- Checking quiz navigation and recommendation logic
- Testing responsive behavior and form interactions
- Documenting prompts and development decisions in `PROMPTS.md`

The prompts and process notes are included in the repository to make the AI-assisted workflow more transparent.

## Limitations

This is a frontend demonstration, not a production-ready lead generation system.

- The lead form does not send data to a server or store submissions.
- No backend or CRM integration is implemented.
- No real user authentication or data processing is involved.
- A production deployment would require appropriate privacy disclosures and consent mechanisms.
- The page should be reviewed against the relevant brand guidelines and legal requirements before any commercial use.

## Potential Improvements

- Connect the lead form to a backend or CRM
- Add form validation and clearer submission states
- Improve keyboard navigation and screen reader support
- Perform cross-browser testing
- Optimize performance and accessibility
- Add analytics integration where appropriate
- Refine the interface based on usability testing
