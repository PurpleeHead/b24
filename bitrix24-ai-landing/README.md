# AI-маркетинговый лендинг — концепт Битрикс24

Адаптивная демонстрационная промостраница с интерактивным квизом и формой заявки. Проект предназначен для портфолио и не является официальным сайтом Битрикс24.

## Что внутри

- `index.html` — структура лендинга и интерфейсные блоки.
- `styles.css` — адаптивная стилизация, карточки, дашборд-мокап, мобильная навигация.
- `script.js` — логика квиза, персональная рекомендация, демонстрация отправки формы.
- `PROMPTS.md` — примеры промптов и краткий журнал AI-процесса.

## Как запустить

1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Для удобной разработки откройте папку в VS Code и используйте Live Server.

Сборка и зависимости не нужны. Шрифт Manrope загружается с Google Fonts; если сеть недоступна, используется системный запасной шрифт.

## Функциональность для проверки

1. Пройдите квиз и проверьте, что рекомендация меняется в зависимости от первого ответа.
2. Попробуйте перейти дальше без выбора — квиз не должен перейти к следующему шагу.
3. На последнем шаге нажмите «Получить рекомендацию».
4. Заполните форму заявки и отправьте её. Это только демонстрация интерфейса: данные не отправляются на сервер и не сохраняются.
5. Проверьте мобильную навигацию и ширину окна 375–430 px.

## Что доработать перед реальным запуском

- Подключить backend/CRM для безопасной обработки заявок.
- Добавить согласие на обработку персональных данных и ссылку на политику конфиденциальности.
- Проверить контент, бренд-гайд и юридические требования правообладателя.
- Пройти тестирование в целевых браузерах и проверить доступность.
